# Data Science Foundations and Analysis

A learning repository containing practical exercises, notebooks, and reference work across the data-science workflow—from Python fundamentals and statistics to exploratory analysis, machine learning, and deep learning.

## Learning roadmap

| Module | Topics |
|---|---|
| 01. Python | Core syntax, data structures, functions and problem solving |
| 02. Statistics | Descriptive statistics, probability, distributions and inference |
| 03. Data analysis | Data cleaning, exploratory data analysis and visualization |
| 04. Machine learning | Regression, classification, model selection and evaluation |
| 05. Dimensionality reduction | PCA and related feature-reduction methods |
| 06. Time series | Temporal data, forecasting and validation |
| 07. NLP and deep learning | Text processing, neural networks and model evaluation |
| 08. Recommendation systems | Collaborative filtering and ranking concepts |
| 09. Python exercises | Practice problems and implementation exercises |
| 10. Interview preparation | Revision notes and technical questions |

## Tools and libraries

Python · Jupyter Notebook · NumPy · Pandas · Matplotlib · scikit-learn · TensorFlow/Keras · XGBoost · LightGBM

## How to use this repository

1. Follow the modules in sequence if you are learning the subject for the first time.
2. Read the concept notes before attempting the related exercises.
3. Run notebooks in order and execute cells rather than only reading the output.
4. Record assumptions, observations, and conclusions in each analysis.
5. For machine-learning exercises, keep training, validation, and test data separate and use metrics appropriate to the task.

## Suggested environment

```bash
git clone https://github.com/Abishek412001/Data-Science-Foundations-and-Analysis.git
cd Data-Science-Foundations-and-Analysis
python -m venv .venv
```

Activate the environment, then install the libraries required by the specific notebook. A single fixed requirements file may not be necessary for every module.
